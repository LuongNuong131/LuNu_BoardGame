# LuNu BoardGame assets

| Asset | Source | Usage |
|---|---|---|
| `frontend/src/assets/boardgame-hero.png` | Generated LuNu visual direction, 2560×1440 | Shared hero and login artwork; deep emerald felt, walnut, brass, cards, chess and mahjong-inspired props; left-side negative space supports readable UI copy. |

The art is intentionally reused as a compact visual anchor across the club dashboard and login page. Game tables themselves use CSS/procedural surfaces so the product remains fast and the live arena can later swap in per-game assets without changing its layout contract.
